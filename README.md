## 项目文件说明

- **Decision_Tree.py**  
  实现了单棵决策树分类模型的代码。

- **AdaBoost + DecisionTrees.py**  
  实现了 AdaBoost 集成决策树模型的代码。

- **HW2_Report.pdf**  
  作业报告文件。

- **README.md**  
  项目的说明文件。

- **SVM.py**  
  实现了支持向量机（SVM）模型的代码。

- **data_generate.py**  
  用于生成三维双月牙数据集的代码。该脚本根据一定的参数生成训练数据集和测试数据集，并存储为 CSV 文件。

- **test.csv**  
  测试数据集。

- **train.csv**  
  训练数据集。
